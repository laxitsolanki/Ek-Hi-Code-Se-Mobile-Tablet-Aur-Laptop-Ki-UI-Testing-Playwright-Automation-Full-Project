# Ek Hi Code Se Mobile, Tablet Aur Laptop Ki UI Testing

Responsive sign-up page and Playwright automation tests for mobile, tablet, and laptop screen sizes.

## Requirements

- Node.js
- Google Chrome

## Setup

```bash
npm install
```

## Run the tests

```bash
npm test
```

## Watch the automation in Chrome

```bash
npm run live-ui
```

## Open the Playwright UI

```bash
npx playwright test --ui
```

The demo sign-up form validates name, email, and password, then demonstrates an OTP step using the demo code `1234`. This is a front-end demo only; it does not send email or create real accounts.
